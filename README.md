# 캐릭터 사진관 📸

레이어 파일(.clip · .psd)이나 PNG 이미지를 올리면 파츠로 정리하고, 파츠를 골라 조합한 캐릭터 포트레이트를 사진처럼 찍어 저장할 수 있는 웹 도구입니다.

- 사이트: https://saturn97v.github.io/character-portrait-studio/
- 만든 사람: 토성([@SATURN97v_](https://x.com/SATURN97v_))
- 해시태그: #캐릭터_사진관_찰칵

올린 파일은 서버로 전송되지 않고, 이용자의 브라우저 안에서만 처리·저장됩니다.

이 프로젝트는 AI(Claude)의 도움을 받아 제작되었습니다.

## 저작권

- 이 페이지의 기획·디자인·이미지(데모 캐릭터 '시범조교 양' 포함)의 저작권은 토성(@SATURN97v_)에게 있습니다.
- 자유롭게 사용해 주셔도 좋지만, 코드나 디자인·이미지를 그대로 복제하거나 수정해서 다시 배포하는 것, 상업적으로 이용하는 것은 삼가 주세요.
